Fewer false alerts

A false alert is an alert for a client without an interceptor. We count them in a real capture and in 100,000 simulated tests for each case.

Before: the paper's step

One step for each site. All changes count the same.

A check failsstep = ln( (1 − θ₁) / (1 − θ₀) ) = +2.08 No check failsstep = ln( θ₁ / θ₀ ) = −1.50

A renewed certificate adds +2.08, the same as a forged certificate.

After: our step

Each check has its own weight. The sum of one site has a cap.

Check failsw = ln( p₁ / p₀ ) Check holdsw = ln( (1 − p₁) / (1 − p₀) ) One sitestep = clip( wA + wB + wD , ±1.84 )

A renewed certificate adds +0.78. A site where all three checks fail adds +1.84.
