Measure each check

The calibrate command compares a clean capture and an attack capture with the baseline. It gives the failure rate of each check, without and with an interceptor.

Failure rate of each check

p₀: no interceptor. p₁: interceptor on the path.

No interceptor (p₀)Interceptor (p₁)

The three checks

One site can fail one, two or three checks.

CheckThe sensor comparesA normal cause of change
AServer fingerprint (JA4S)New server software
BCertificate keyCertificate renewal
DNetwork path (TTL)New route

TLS 1.3 hides the certificate, so check B is not available on most sites.

Give each check a weight

The paper adds the same step for any change. We give each check its own weight from its two rates.

Weight of each check

Right: the check failed. Left: the check held.

Check failedCheck held

The formula

Log-likelihood ratio of each check

failed:  weight = ln(p₁ / p₀)
held:    weight = ln((1 − p₁) / (1 − p₀))
site step = sum of the weights of its checks

Set a cap for each site

A cap limits the step of one site. A smaller cap gives fewer false alerts, but the sensor needs more sites to find an interceptor.
